# Diagramas da arquitetura

Os nove diagramas estão em `diagramas/`, nos formatos PNG para leitura, SVG vetorial e DOT para edição/regeração com Graphviz. São visões propostas do CondPulse, não inventário de um ambiente existente.

01 Contexto; 02 Topologia de implantação; 03 Organograma e responsabilidades; 04 Módulos; 05 Modelo lógico residencial; 06 Modelo de integração; 07 Ciclo facial; 08 Reserva; 09 Fases e gates.

O SQL é a referência detalhada de relações; os desenhos agrupam algumas entidades para leitura. O PRD registra os limites do escopo, as decisões e as dependências externas.
