# Claude Code — CondPulse v2.0

Instruções do projeto para o Claude Code. Regra ou decisão nova entra aqui,
para valer em toda sessão e em todo computador.

## Como trabalhar

- Sempre em português do Brasil. Fuso: America/Sao_Paulo.
- Não inventar números, datas, nomes ou fatos sobre o produto. O que ainda
  não foi decidido fica marcado como pendente.
- Nunca dizer "está feito" sem prova (teste, comando ou página conferida).

## Segurança

- Nunca mostrar, copiar ou commitar chave, token ou senha. Arquivos `.env*`
  ficam fora do Git (ver `.gitignore`).
- Gasto com serviço pago só com OK explícito do responsável.

## Git

- Trabalho em branch própria → PR → revisão → merge.
- Não forçar push, não reescrever histórico de branch compartilhada.
